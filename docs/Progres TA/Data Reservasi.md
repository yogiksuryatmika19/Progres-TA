## Data Reservasi

Adapun data yang telah diperoleh langsung dari Kashantee Village yaitu data reservasi berbentuk time-series dengan rentang waktu dari tahun ***2019*** sampai ***2025***

### Data Head

Berikut adalah tampilan bagian awal dari data yang telah diperoleh

![](../Images/Data%20Reservasi-2.png)

### Data Kolom

Adapun jumlah kolom yang diperoleh dari data reservasi memiliki ***10 buah kolom***. Berikut adalah detail dari kolom-kolom yang diperoleh pada data reservasi

| Kolom                | Keterangan                                 |
| -------------------- | ------------------------------------------ |
| `Reservation Number` | id reservasi                               |
| `Name`               | nama depan guest                           |
| `Surname`            | nama belakang guest                        |
| `Arrival Date`       | tanggal check-in                           |
| `Departure Date`     | tanggal check-out                          |
| `Room Nights`        | jumlah berapa malam menginap               |
| `Guests`             | jumlah guests ketika check-in dalam 1 room |
| `Room Type`          | jenis room                                 |
| `Room(s)`            | nomor room                                 |
| `Reservation Status` | status reservasi                           |
